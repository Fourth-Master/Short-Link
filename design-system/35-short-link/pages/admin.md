# Admin override

- Pattern: Data-Dense Dashboard
- Density: 8/10, with 12–14px table text and 40–44px controls
- Desktop sidebar is persistent; mobile navigation collapses without horizontal page scroll
- Tables prioritize scanability, stable column widths and clear destructive actions
- Use non-blocking toasts for informational success/error feedback; keep explicit confirmation for destructive operations
- Modal dialogs trap intent with visible close/cancel paths and Escape support
