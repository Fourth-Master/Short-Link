35短链 API 文档

通过一个简单的 HTTP 接口生成支持自定义短码和有效期的短链接。

生成短链接 API

将原始长网址转换为短链接，可选择自定义短码和有效期。

接口路径/api/create
请求方法POST

请求参数

参数名类型必填说明
longUrlstring是需要缩短的 HTTP 或 HTTPS 原始网址。
customCodestring否6 至 12 位字母数字短码；留空时自动生成。
expireDaysnumber否有效期天数，默认 30 天，最大 365 天。

请求示例

{
  "longUrl": "https://www.example.com/abc",
  "customCode": "mycode123",
  "expireDays": 30
}

返回示例

{
  "status": 1,
  "code": "mycode123",
  "shortUrl": "__SITE_URL__/s/mycode123",
  "expire": 1718889600000
}

status=1 表示生成成功，shortUrl 为可直接分享的短链接。

错误响应

请求参数、网址格式或自定义短码不符合要求时，接口会返回具体错误信息。

{
  "status": 0,
  "msg": "错误信息"
}
